网页视频字幕提取工具
========================

重要：如果下载的是 ZIP 压缩包，请先右键选择“全部解压”。
不要在 ZIP 压缩包内部直接运行工具。

1. 双击“启动字幕工具.vbs”。
2. 粘贴视频页面地址，也可粘贴从 F12 网络面板复制的 m3u8 地址。
   也支持直接粘贴 MP4、WebM、MOV、MKV、M4V、TS、MP3 或 M4A 直链。
3. 选择“智能字幕提取”“极速字幕（语音识别）”“仅提取 MP3 音频”或“下载 MP4 视频”，然后点击“开始处理”。
4. 程序依次检查网页原字幕、视频字幕轨和画面硬字幕；都不可用时再用 Whisper 语音识别。
5. 下载音频或 OCR 视频时，进度条会显示百分比、速度和预计剩余时间。
6. 只有任务完整成功后才保留独立结果文件夹；失败任务会自动清理。
7. 需要中止时点击“取消任务”；程序会停止后台下载/识别并清理未完成文件。
8. 关闭窗口时如果任务仍在运行，程序会先询问是否取消并等待清理完成。
9. 任务运行时会显示“已用时”，结束后显示总处理时长和各阶段耗时。
10. 成功后任务栏会闪烁，完成弹窗可选择立即打开本次结果文件夹。

词汇统计：
- 主窗口上方有“字幕提取”和“词汇统计”两个标签页，仍然使用同一个启动入口。
- “词汇统计”页顶部可以切换、新建和重命名词汇表。新词汇表从 0 开始独立累计；默认词汇表保存升级前的全部历史且不能删除。
- 同一份字幕可以分别导入不同词汇表；在同一个词汇表中再次导入才会判定 duplicate。搜索、排序、分页、撤销和历史累计都只针对当前词汇表。
- 删除用户创建的词汇表会永久删除该表的导入历史和累计统计，但不会影响默认词汇表或其他词汇表；删除前程序会再次确认。
- 本次运行中成功完成字幕提取后，“分析词汇”按钮会启用；点击后程序分析该次最终清洗字幕并进入词汇页。
- 也可以在“词汇统计”页点击“导入字幕文件”，选择已有的 SRT、VTT、ASS 或 TXT 字幕直接统计。
- 只有字幕结果可以分析；MP3、MP4、失败任务以及没有明确成功目录的任务不会启用该按钮。
- “累计出现次数”是该单词在历次成功统计字幕中的长期总数，不是当前这一份字幕中的次数。
- “英语总体词频”是 wordfreq 提供的离线 Zipf frequency；数值越高通常表示在总体英语中越常见。
- 词频显示保留两位小数，并附带“极常见、很常见、常见、较少见、少见、非常少见”标签；标签只用于显示，不改变数据库中的原始数值。
- 每次导入成功后会另开“本次导入结果”窗口，分别显示本次出现次数和当前历史累计次数；窗口支持英文搜索、八种排序和每页 200 条分页，原“词汇统计”页继续显示全部历史词库。
- 非重复的新导入可以在本次结果窗口点击“撤销本次导入”；确认后，该字幕贡献的累计次数会从历史词库扣除，并可在以后重新导入同一字幕。重复导入没有新增历史记录，所以撤销按钮不可用。
- 主“词汇统计”页可点击“放大表格”最大化查看更多行，再点击“恢复窗口”回到原来的大小和位置；这不会改变每页 200 条的数据库分页。
- 重复字幕会显示原导入的本次结果，并明确提示本次没有再次累计。
- 公开包只附带 Kaikki 主词典。如用户自行拥有兼容的 ECDICT SQLite，可放到“用户数据\vocabulary_resources\ecdict.sqlite3”作为本地释义补充；该第三方数据不会随项目公开分发。
- 中文释义未收录时显示“未收录”，英语词频未收录时显示“—”。
- 搜索框只搜索英文单词，输入后按 Enter 或点击“搜索”；排序和每页 200 条分页均由程序后台查询。
- 同一份最终字幕再次点击分析时不会重复累计，程序会提示“本次没有重复累计”，然后正常刷新词表。
- 任务结果与手动选择的文件共用正文去重；只要最终清洗后的字幕正文相同，就不会重复累计。
- 词表保留普通英文单词和 part-time、well-known、mother-in-law 这类连字符词；don't、isn't、I'm 等缩写及 GPT5、10bbc 等含数字项目不会进入词表。
- the、a、is、are、have、do、I、you 等少量超基础功能词默认不统计或显示；该规则使用明确的小型基础词表，不会按英语词频数值机械删除 actually、probably、instead 等学习词。
- 词汇质量规则只保留有正常中文释义的词，即使它很冷门；没有释义的项目无论 Zipf 数值多高都会被过滤。Zipf 只表示总体英语中的常见程度，不决定是否收录；程序不使用不断扩大的单词黑名单。
- 旧数据库不会因规则调整被清空或重建；旧的无效或超基础词只在当前词表中隐藏，历史数据仍保留。

极速字幕说明：
- 极速模式先尝试无需下载完整视频的网页或远程字幕。
- 没有远程字幕时，只下载音频并使用较快的 Whisper base 模型识别。
- 极速模式跳过 OCR 视频下载、内嵌字幕轨检查和画面硬字幕识别，通常明显更快。
- 因此可能漏掉画面烧录文字、无配音文字及只封装在完整视频文件内部的字幕轨。
- 需要尽可能完整地保留画面文字时，请使用“智能字幕提取”。

下载说明：
- 智能字幕的 OCR 临时视频优先选择最高不超过 480P；没有合适流时回退到 720P，
  用较小下载量加快 OCR，且不会改变“下载 MP4 视频”的成品画质。
- OCR 临时视频优先使用 12 路分片；完整 MP4 优先 8 路，并会在普通网络错误时
  自动逐级降档到稳速和单路续传。
- 视频分片出现 SSL EOF 或不可用时，会立即放弃坏线路并切换备用线路。
- m3u8 候选线路会用 FFmpeg 短读真实媒体分片，不再只判断播放清单能否打开。
- 成功线路只按“网页主机→媒体主机”缓存 7 天，不保存网址查询参数或签名令牌。
- 网络或网站持续不可用时，任务会明确失败，不会无限显示“处理中”。
- “下载 MP4 视频”默认选择源站最高不超过 1080P 的清晰度，并自动合并音视频。
- MP4 模式优先选择 Windows 播放器兼容性较好的 H.264 视频和 AAC 音频；
  源站没有时会自动回退到其他可用编码。
- 下载完成后会用 ffprobe 检查 MP4 是否可解析且包含有效视频流。

磁盘空间保护：
- MP3 下载开始前至少需要 1 GB 可用空间。
- 智能字幕需要下载 OCR 临时视频时至少需要 2 GB。
- 完整 MP4 视频下载开始前至少需要 3 GB。
- 空间不足时任务会在下载前停止，不会等到合并阶段才失败。

常见失败提示：
- 403：链接可能已经过期，或网站需要登录。
- 登录/Cookie：当前地址不能直接访问受账号保护的视频。
- DRM：加密视频无法由本工具下载。
- 暂不支持：可以尝试从 F12 网络面板复制 m3u8 或 MP4 直链。
- 403、DRM、需要登录、不支持 URL 和磁盘不足属于确定性错误，程序会立即停止，
  不会再进行一次没有意义的单路重试。

网页线路兼容：
- 支持网页脚本里的普通、`\/` 转义、HTML 实体、协议相对、根相对和路径相对 m3u8。
- 网站自定义播放接口失效时，会继续尝试标准线路或交给 yt-dlp 解析。
- 如果 Python 网络库与网站 TLS 不兼容，会自动切换 Windows 原生网络栈，
  不会通过关闭证书验证来绕过安全检查。
- 网站返回多条播放线路时，会优先尝试近期成功的媒体主机，并检测真实媒体分片；
  第一条真实可用线路通过后立即开始，保留其余线路按需切换。

详细日志：
- 下载过程中每跨过 10% 记录一次速度和预计剩余时间，不会按每个分片刷屏。
- 程序会清除第三方组件的颜色控制符，日志更适合直接阅读和反馈问题。
- 运行记录会分别写入线路解析、远程字幕、媒体下载、OCR/语音识别和结果整理耗时。

正式组件版已自带 yt-dlp、CPU RapidOCR 和 Faster-Whisper，但不分发 ffmpeg.exe/ffprobe.exe 命令行程序。
部分随 Python 包提供的 native 组件可能包含 FFmpeg libraries；其清单、许可证和审计状态以 THIRD_PARTY_LICENSES/COMPONENTS.json 为准。
v1.0.0 正式包不包含 NVIDIA/CUDA GPU OCR runtime；硬字幕 OCR 功能仍然存在，默认使用 CPU，处理速度可能比开发环境的 GPU 模式慢。
请自行安装 FFmpeg 并加入 PATH；安装后可在命令行运行“ffmpeg -version”和“ffprobe -version”确认。
开发者可以把自备的 ffmpeg.exe 与 ffprobe.exe 成对放入 runtime\bin，程序会优先使用；正式公开 ZIP 不包含它们。
工具已自带 Python 3.12 和 pip，不需要另外安装 Python。
普通智能模式的 Whisper 兜底使用 small 模型；极速字幕模式使用更快的 base 模型。

广告净化：
- OCR 会过滤常驻站点号、官网/赞助标志、博彩推广组合、制作名单、版权文字和明显乱码。
- 对 OCR 破损后残留的“炸金花/捕鱼”等广告尾巴会结合上下文清理。
- Whisper 只清理强广告标志和长推广组合，避免把正常口语中的“棋牌”“澳门”“捕鱼”等词误删。

输出：
- SRT：带时间轴的字幕文件
- TXT：清理后的纯文字
- MP3 模式：生成“视频音频.mp3”
- MP4 模式：生成“下载视频.mp4”
- 硬字幕 OCR 成功时会生成“硬字幕OCR.srt”和“硬字幕OCR文字.txt”

维护：
- 失败任务不会保留结果文件夹，但会在“失败日志”目录保留一份小型诊断日志。
- 失败日志最多保留最近 30 份。
- “清理缓存”只统计并清理超过 24 小时的 .part/.ytdl 临时下载文件。
- 清理前会显示文件数量和容量，必须确认后才会执行。
- 清理缓存不会删除 MP3、MP4、SRT、TXT、运行日志或成功结果。

注意：
- runtime 是程序运行文件夹，请不要删除或移动其中的文件。
- 项目自有代码采用 GPL-3.0-or-later；第三方组件和数据继续遵循 THIRD_PARTY_LICENSES 及各资源 LICENSES 中自己的许可证。
- 普通用户应使用正式 portable ZIP，并完整解压后运行；不要把源码或开发目录自行压缩当作发布包。
- 正式下载位置应同时提供 portable ZIP 和 third-party-source ZIP。项目实际分发的 yt-dlp 许可证与来源说明位于 THIRD_PARTY_LICENSES。
- FFmpeg CLI 是用户自行安装的外部依赖，ffmpeg.exe/ffprobe.exe 不随本项目 Release 分发；项目不会在启动时从第三方站点自动下载它。
- 正式包不包含 runtime\gpu_runtime；这不关闭硬字幕 OCR，只会使用 CPU 后端。
- 正式包不包含本地 ECDICT，也不应包含用户数据库、字幕结果或失败日志。
- 登录限制、DRM 加密或强防盗链视频可能无法获取。
- 普通网页解析最多读取 16 MB；大型视频直链不会被整个载入内存。
- 启动时会检查 ffprobe、网页解析器和“字幕结果”目录写入权限。
- MP4 完成后除视频流外还会验证媒体时长，降低不完整文件被误判成功的概率。
- 请只处理你有权访问和使用的视频。
